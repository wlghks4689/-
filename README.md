# 사이 — 무료대화 소개팅 앱 프로토타입

기획서 v0.1의 Phase 0~1을 구현한 웹 프로토타입입니다.

## 현재 구현

- 회원가입/로그인 화면과 입력 검증
- 프로필 생성·조회·수정
- 프로필 사진 1장 업로드 및 미리보기(3MB 제한)
- 로그아웃
- 모바일 반응형 화면

현재 인증과 프로필은 브라우저 `localStorage`를 사용하는 데모입니다. 실제 개인정보를 입력하지 마세요.

## 실행

```bash
npm install
npm run dev
```

## 임시 결정과 TODO

- 서비스명은 임시로 `사이`를 사용합니다.
- 웹/PWA 우선으로 제작했습니다.

- 결제, 채팅 슬롯, 후원, 신고/차단은 현재 Phase 범위 밖입니다.
